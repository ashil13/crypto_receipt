# Crypto Receipt

سایتی ساده: آدرس کیف پول Ethereum را وارد کن، یک کارت رسید زیبا از سابقه‌اش بساز، دانلود و در X شیر کن.

## اجرا روی سیستم خودت

```bash
npm install
npm run dev
```

بعد آدرسی که در ترمینال نشان داده می‌شود (معمولاً `http://localhost:5173`) را در مرورگر باز کن.

برای build نهایی:

```bash
npm run build
npm run preview
```

## API / سرویس

- **بدون هیچ کلید یا سرویس پولی**، اپلیکیشن کامل کار می‌کند: موجودی ETH و تعداد تراکنش‌های ارسالی از یک RPC عمومی و رایگان Ethereum Mainnet خوانده می‌شود.
- **اختیاری:** اگر یک کلید رایگان از [etherscan.io/apis](https://etherscan.io/apis) بگیری و آن را داخل فایل `.env` (بر اساس `.env.example`) به‌صورت `VITE_ETHERSCAN_API_KEY=...` قرار بدهی، سه فیلد اضافه هم نمایش داده می‌شود: تعداد کل تراکنش‌ها، تاریخ اولین فعالیت، و عمر کیف پول.

## محدودیت‌های اطلاعات

- «تعداد تراکنش‌ها» بدون کلید Etherscan فقط تراکنش‌های **ارسالی** از آدرس را می‌شمارد (nonce)، نه تراکنش‌های دریافتی.
- «تعداد قراردادهایی که تعامل داشته» در این نسخه ساخته نشده، چون محاسبه دقیق و رایگان آن نیاز به درخواست‌های زیاد و پیچیده دارد و با هدف «ساده نگه داشتن پروژه» در تضاد بود.
- برای کیف‌پول‌های بسیار پرتراکنش، شمارش Etherscan ممکن است سقف داشته باشد (این مورد در کد و در کارت با علامت «+» مشخص شده).
